# Version 18 Build 4 App Store / Website Images

Created 2026-07-19 for the Version 18 Build 4 update page and App Store asset review, carrying forward the refreshed planner-chain, optional PWS weather source, and two-digit ALT report polish images.

Build 4 remarks add the current planner fixes: startup clears selected targets unless a saved plan is loaded from Planner, Home and Weather date changes use one confirmation gate before clearing an in-progress plan, and adding a newly checked target to an existing Planner chain resequences the chain by first-visible order.

Final build remarks also include the nightly cellular-data prompt: when Wi-Fi is unavailable, Weather and Set Up internet updates ask whether cellular data may be used for the selected observing night.
